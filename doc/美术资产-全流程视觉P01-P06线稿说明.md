## 一、通用线稿规范

| 项 | 规范 |
|---|---|
| 画布基准 | 竖屏 750rpx 宽（等比缩放，逻辑像素 375 宽），页面左右安全边距 48rpx |
| 圆角 | 卡片 32rpx，按钮 999rpx（全圆），内嵌小卡 20rpx |
| 色值 Token | `--bg-deep` `#1B1035`、`--bg-sub` `#2A1B4A`、`--gold` `#E8C87A`、`--ivory` `#F5EFE6`、`--violet` `#C9B6FF`；背景渐变 135° `#1B1035` → `#3A2A6B`（均取自 PRD 5.2） |
| 字体 | 标题：霞鹜文楷 LXGW WenKai；正文：思源黑体 / 阿里巴巴普惠体（均需法务复核授权） |
| 线描风格 | 细金线描符号，线宽视觉 2rpx；符号不带写实阴影 |
| 免责提示 | 字号 24rpx（不得低于 24rpx，禁止以超小字号或折叠隐藏） |
| 功能图标 | 统一 24 × 24 单位网格，线宽 1.6 单位，圆头端点与转角，展示尺寸 52rpx，交互热区 ≥ 88 × 88rpx；全库单色（默认 `#E8C87A`，弱化态 55%）；**图标编号与替换指引见《美术稿-功能图标库.html》（含同名 PNG）** |
| 通用禁止元素 | 真实占卜牌完整版式、宗教符号误用、吉凶 / 运势类文字、血腥恐怖元素 |

### 6.5 对照带绘制规则（美术与研发对齐）

- 每条对照带两端标注该维度的 A / B 端名称（如 D1「外显 — 内隐」）。
- 两名用户各用一个星点表示，位置对应其主导端：
  - **一致**：两点落在同一端，视觉上重叠为一点并加金色光晕，右侧标「一致」。
  - **互补**：两点分列两端，中间以虚线相连，右侧标「互补」。
- 标记色不区分优劣：一致与互补均使用 `--gold`，**不得使用红 / 绿等暗示好坏的颜色**。
- 图谱不展示任何分数排名、胜负或优劣暗示。
