**适用**：抖音小程序《星语人格 · 好友同频测试》短视频挂载素材、小程序推广计划（达人推广挂载）达人素材
**面向**：达人脚本、投放运营
**上游依据**：PRD 7.1 流量分发、7.2 分享裂变；风控口径见 PRD 4.3、8.2；平台规则来源见《平台规则检索记录.md》R-4、R-7

> 本文件只规范「素材怎么说、怎么拍、怎么挂」，不含平台结算规则与任务定价——那些随平台当期政策确认（见 PRD 7.1）。

## 二、选题方向（按达人类型）

`【内容叙事】`

| 达人类型 | 内容角度 | 建议切入 |
|---|---|---|
| 情感类 | 关系观察 | 比较两个人的相处模式差异，不做关系好坏判断 |
| 心理科普类 | 自我认知 | 用「原型 / 倾向 / 偏好」讲人格偏好，不涉诊断与测评准确率 |
| 星座塔罗类 | 图像符号意象 | 以符号与卡面的视觉美感切入，**不解读运势、不做星盘合盘** |
| 颜值 / 生活类 | 闺蜜互动 | 双人同框完成测试的全过程，突出互动与反应 |

**分类型约束**

- 心理科普类：不得使用「心理测评」「准确率」「专业量表」「诊断」表述。
- 星座塔罗类：不得将天体符号、卡牌意象与命运、吉凶、运势建立关联。
- 全类型：产品口径统一为「趣味叙事娱乐测试」，见 PRD 4.1。

## 三、3 秒钩子模板（8 条）

`【内容叙事】` 钩子置于视频前 3 秒（对齐 PRD 7.1）。

**A. 好奇缺口型**

1. 原来我和闺蜜相处起来，是这样的模式……
2. 同一个问题，我和她的答案完全相反

**B. 关系共鸣型**

3. 测完才发现，我们俩的差异一直在互补
4. 找搭子之前，先看看你们合不合拍

**C. 结果悬念型**

5. 我的结果是一张映像卡，她是另一张
6. 十分钟前还不算熟，现在大概知道为什么聊得来

**D. 挑战邀请型**

7. 拉上你最常聊天的那个人，一起测一次
8. 十道题，看看你们的相处模式是哪一种

**统一约束**：钩子不得出现绝对化断言，不得暗示预测未来、改变处境或决定关系走向。

## 四、口播脚本模板

### 模板 1｜过程型（单人，30–45 秒）

| 时间 | 画面 | 字幕 | 口播 |
|---|---|---|---|
| 0–3s | 达人正脸 + 钩子字幕（用 A/C 类钩子） | 钩子文案 | 念钩子 |
| 3–8s | 小程序首页，手指点击「开始测试」 | 十道题 · 约 3 分钟 | 「十道题，选第一感觉就行」 |
| 8–25s | 答题过程快剪，展示 2–3 道题与选项 | 进度 3/10 等真实进度 | 「有的题我真的犹豫了」 |
| 25–33s | 结果卡揭晓，展示原型符号与原型名 | 原型名 + 主导意象 | 「我的原型是曜日型」 |
| 33–40s | 点击「邀请好友配对」，展示邀请卡 | 邀请对方一起测 | 「想看看我和她是什么模式」 |
| 40–45s | 结尾定格 + 锚点提示 | **娱乐测试 · 结果仅供参考** | 「点下面挂载，测测你的」 |

### 模板 2｜双人互动型（闺蜜同框，45–60 秒）

| 时间 | 画面 | 字幕 | 口播 |
|---|---|---|---|
| 0–3s | 双人同框，各自举手机 | 用 B/D 类钩子 | 念钩子 |
| 3–20s | 两人并排答题，对选项互相吐槽 | 各自进度 | 「她选这个我完全不意外」 |
| 20–35s | 两张结果卡对比展示 | 两个原型名 + 主导意象 | 「我们俩居然是互补型」 |
| 35–50s | 同频图谱揭晓，4 条对照带依次点亮 | 同频度 + 相处模式标签 | 「两处一致、两处互补」 |
| 50–60s | 双人反应 + 锚点提示 | **娱乐测试 · 结果仅供参考** | 「拉你最常聊天的人一起测」 |

### 模板 3｜结果展示型（快节奏，15–25 秒）

| 时间 | 画面 | 字幕 | 口播 |
|---|---|---|---|
| 0–3s | 结果卡特写，符号先入画 | 钩子（C 类） | 念钩子 |
| 3–12s | 三条特质文案逐条上屏 | 特质原文 | 「这几条我都中了」 |
| 12–20s | 切到配对图谱 | 同频度 + 相处模式 | 「和她测出来是均衡互补型」 |
| 20–25s | 锚点提示 | **娱乐测试 · 结果仅供参考** | 「挂载里就能测」 |

## 七、风控约束（必读）

`【产品功能】`（执行项）+ `【内容叙事】`（措辞项）

1. **禁用词**：命中「命中注定、一定会、宿命、吉凶、预言、转运、算命、预测未来」任一即不得上线（词表见 PRD 4.3）。
2. **禁用表述**：不得出现心理测评准确率、专业诊断、运势解读、付费改运、结果翻盘等承诺（同 PRD 7.3 合规约束）。
3. **上线前扫描**：达人素材与自行投放素材在发布前均须过禁用词扫描，方式与 PRD 4.3 一致。
4. **必备标识**：每条素材结尾须带「娱乐测试 · 结果仅供参考」。
5. **不得诱导**：不得以强制分享、分享后解锁、拉人才能出结果等方式设计钩子（同 PRD 7.2）。
6. **达人侧独立禁令**：平台《小程序达人管理规范》对达人运营内容另有「不得出现封建迷信相关内容」的独立要求，分享素材亦有同类标准（来源见《平台规则检索记录.md》R-7）。达人素材除满足本规范外，须同时满足该口径。

## 八、素材校验清单（发布前逐条勾选）

- [ ] 前 3 秒钩子不属绝对化断言，不暗示预测未来或决定关系走向。
- [ ] 脚本未出现 PRD 4.3 八个禁用词中的任何一个。
- [ ] 未出现心理测评准确率、专业诊断、运势解读类表述。
- [ ] 结尾「娱乐测试 · 结果仅供参考」标识在位且可读。
- [ ] 天体符号与卡牌意象仅作视觉素材，未与命运、吉凶、运势关联。
- [ ] 画面未使用真实占卜牌完整版式、宗教性标识、恐怖元素。
- [ ] 锚点落地为 P-01，非中间态页面。
