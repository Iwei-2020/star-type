# 合规资产 · 提审自检清单

**适用**：抖音小程序《星语人格 · 好友同频测试》首次提审与后续版本更新
**面向**：产品、研发、内容（文案 / 美术）
**上游依据**：PRD 8 平台合规与风控、4.3 禁用词表、4.4 免责文案、5.2 禁止元素、7.2 / 7.3 合规约束

> 平台侧规则（类目、资质、材料要求）与发行人结算政策随平台当期政策确认。本清单中标注 `[TBD]` 的条目**须在提审前向平台侧核实，不得凭经验填写**。

---

## 一、使用方式

1. 每次提审前逐项勾选，**存在未通过项不得提交**。
2. 交叉复核分工：内容侧负责第三节至第四节，研发侧负责第五节至第六节。
3. 勾选结果与日期随版本留档（对齐 PRD 第 9 章数据口径的版本意识）。

## 四、内容合规自检（逐项）

### 4.1 禁用词

- [ ] 八个禁用词——命中注定、一定会、宿命、吉凶、预言、转运、算命、预测未来——在小程序内**零命中**。
- [ ] 扫描范围覆盖：页面文案、题干与选项、16 原型解读、配对页叙事、分享卡文字、卡面与印章等视觉文字、达人挂载文案。
- [ ] 图内文字已人工复核（扫描脚本不识别图片内文字，见 PRD 4.3 对视觉文字的要求）。

### 4.2 定位表述

- [ ] 六处免责全部常驻且可读：P-01 / P-02 / P-03 / P-04 / P-05 / P-06。
- [ ] 免责字号不低于 24rpx，未折叠、未隐藏、未以弹窗一次代替常驻。
- [ ] 首页与引导页无「测评准确率」「专业」「诊断」「量表」类表述。

### 4.3 占星塔罗边界

- [ ] 天体符号与卡牌意象仅作视觉与叙事素材，未与命运、吉凶、运势建立关联。
- [ ] 无星盘合盘、无运势解读、无吉凶判断类功能或文案。
- [ ] 无真实占卜牌完整版式、无宗教性标识（对齐 PRD 5.2 禁止元素）。
- [ ] 全稿无「风水命理、算命、解梦」类表述——平台信用分规则对此设有明确扣分项（违背公序良俗，扣 5～10 分），见《平台规则检索记录.md》R-3。

### 4.4 分享与广告

- [ ] 无强制分享、分享后解锁、拉人才能出结果等设计。
- [ ] 广告未伪装为测试结果或功能按钮，且与结果卡保持可识别间距。
- [ ] 无付费改运、结果翻盘类能力或暗示。

## 八、红线速查（一票否决）

任一为「是」即不得提审，须先整改。

| 检查项 | 若为「是」→ 处置 |
|---|---|
| 存在运势、吉凶或未来推断的功能或文案 | 删除功能与文案，全量重新扫描 |
| 宣称心理诊断、专业测评或准确率 | 统一改为「趣味叙事娱乐测试」口径（PRD 4.1） |
| 以预测命运、改变处境作为卖点或钩子 | 更换卖点与钩子（对齐达人素材规范第三节约束） |
| 强制分享或诱导分享 | 改为自愿分享 |
| 以付费改变测试结果 | 移除该能力 |
| 使用宗教性标识或真实占卜牌完整版式 | 替换素材 |
| 免责文案缺失、被折叠或字号过小 | 补齐并升至 24rpx 以上 |

## 九、易踩线场景自查（本产品专属）

`【内容叙事】` 整改项，按本项目已产出的文案与素材逐一比对。

| 易踩线写法 | 整改为 |
|---|---|
| 首页写「测测你的运势」 | 「测测你的性格倾向」 |
| 原型解读写「命中注定的搭子」 | 「相处起来更合拍的搭子」 |
| 配对页写「你们的友情未来走向」 | 「你们的相处模式」 |
| 达人脚本把卡牌意象与「接下来三个月」绑定 | 删除时间性推断，只讲符号与叙事 |
| 结果页广告紧贴结果卡且样式近似 | 加广告标识并拉开间距 |
| 分享卡漏放免责 | 补「娱乐测试 · 结果仅供参考」 |

**说明**：本节场景取自本项目已产出的文案资产、达人素材规范与美术稿，非平台驳回统计；目的是把已写下的措辞逐条对回红线。

## 十、维护与留档
