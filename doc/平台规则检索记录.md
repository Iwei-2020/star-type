## R-4 短视频挂载与达人推广（**对 PRD 7.1 的实质修正**）

| 项 | 检索值 | 来源 |
|---|---|---|
| 小程序对应能力 | 短视频**自主挂载**（基础能力，绑定抖音号即可）+ 短视频**达人推广挂载能力**（需申请）+ 小程序推广计划 / 小程序任务台 | 短视频达人推广挂载能力、短视频自主挂载 |
| 开通条件 | 小程序信用分 ≥ 60 分；主营类目符合「达人推广挂载能力类目开放类型」；须签署《小程序任务台推广协议》 | 短视频达人推广挂载能力开通规范 |
| 能力审核侧重 | 功能实用性、界面设计、交互体验、稳定性，及产品思路与定位的创新性、普适性 | 同上 |
| 任务形式 | 通发任务、指派任务（圈人群，仅名单内作者可见）、奖金活动、机构合作 | 出价原理文档（小游戏口径，参考） |
| 分成口径 | 分成 = 开发者广告收益 × 开发者配置的达人分成比例 | 达人推广相关文档 |
| 结算节奏 | 次月初生成流量主结算单，扣除前一个月的达人佣金 | 同上 |
| 流量参考 | 「短视频挂载通常可以为工具类小程序贡献高达 85% 的流量」（平台社区口径，**非官方统计**） | 平台社区文章 |

**重要修正**：检索到的「**游戏发行人计划**」文档均归属**小游戏**（mini-game）。小程序侧对应通路是「短视频达人推广挂载 + 小程序推广计划 / 任务台」，并非小游戏的发行人计划。
→ 因此 **PRD 7.1 需将「发行人计划」修正为「小程序达人推广挂载 + 小程序推广计划」，并补充开通条件（信用分 ≥ 60、类目要求、签署协议）。**

## R-5 广告变现（流量主）

| 项 | 检索值 | 来源 |
|---|---|---|
| 支持的广告类型 | 激励视频广告、信息流广告 | 流量主能力页 |
| 准入条件 | 无严重违规行为 | 同上 |
| 开通路径 | 控制台 → 设置 → 商业化变现 → 申请开通，并同意《字节跳动小程序广告组件系统服务协议》 | 广告接入指南 |
| 结算注意 | **仅线上状态的小程序调用广告才产生收益**，未上线版本不产生收益 | 企业主体小程序流量主结算指南 |

**对 PRD 7.3 的意义**：原定的「激励视频 1 处 + 结果页原生广告位 1 处」在小程序侧有对应能力（激励视频 = rewarded video，原生位可归入信息流位），方案成立；但需补记「须先开通流量主」与「上线后才产生收益」两条前置事实。

## R-7 内容安全

| 项 | 检索值 | 来源 |
|---|---|---|
| 分享素材 | 不得出现封建迷信内容；不得违背社会公序良俗 | 分享素材审核标准 |
| 达人侧 | 达人运营不得出现封建迷信相关内容 | 小程序达人管理规范 |
| 运营规范 | 虚假迷信归属「煽动夸大误导」类违规 | 小程序运营规范 |
| 信用分 | 内容含封建迷信（风水命理、算命、解梦）扣 5～10 分 | 小程序信用分管理规则 |

**对 PRD 4.4 / 提审清单的意义**：免责措辞中「不构成任何形式的命运、运势或未来推断」这一表述有平台规则依据支撑；分享卡与达人素材须纳入同一扫描范围（平台对分享素材与达人内容均有独立禁令）。
