## R-4 短视频挂载与达人推广（**对 PRD 7.1 的实质修正**）

| 项 | 检索值 | 来源 |
|---|---|---|
| 小程序对应能力 | 短视频**自主挂载**（基础能力，绑定抖音号即可）+ 短视频**达人推广挂载能力**（需申请）+ 小程序推广计划 / 小程序任务台 | 短视频达人推广挂载能力、短视频自主挂载 |
| 开通条件 | 小程序信用分 ≥ 60 分；主营类目符合「达人推广挂载能力类目开放类型」；须签署《小程序任务台推广协议》 | 短视频达人推广挂载能力开通规范 |
| 能力审核侧重 | 功能实用性、界面设计、交互体验、稳定性，及产品思路与定位的创新性、普适性 | 同上 |
| 任务形式 | 通发任务、指派任务（圈人群，仅名单内作者可见）、奖金活动、机构合作 | 出价原理文档（小游戏口径，参考） |
| 分成口径 | 分成 = 开发者广告收益 × 开发者配置的达人分成比例 | 达人推广相关文档 |
| 结算节奏 | 次月初生成流量主结算单，扣除前一个月的达人佣金 | 同上 |
| 流量参考 | 「短视频挂载通常可以为工具类小程序贡献高达 85% 的流量」（平台社区口径，**非官方统计**） | 平台社区文章 |

**重要修正**：检索到的「**游戏发行人计划**」文档均归属**小游戏**（mini-game）。小程序侧对应通路是「短视频达人推广挂载 + 小程序推广计划 / 任务台」，并非小游戏的发行人计划。
→ 因此 **PRD 7.1 需将「发行人计划」修正为「小程序达人推广挂载 + 小程序推广计划」，并补充开通条件（信用分 ≥ 60、类目要求、签署协议）。**

## R-8 服务端载体与调用来源校验（**对技术资产 §1.1 与 §6 的收口**）

| 项 | 检索值 | 来源 |
|---|---|---|
| 官方载体是否存在 | **有。** 抖音云（一站式后端服务托管），面向抖音生态的小程序 / 小游戏 / 小玩法；含「函数服务」（Node.js 等，支持在线编辑器、本地开发、CLI 部署）与「云托管」（自定义 Docker 镜像部署）两条路径 | 抖音云官网 · 产品简介 · 「10 分钟快速部署自定义服务」 · 本地开发函数服务 |
| 小程序端调用形态 | `tt.createCloud({ envID, serviceID })` → `cloud.callContainer({ path, init })`；`createCloud` 为同步方法，返回 Cloud 实例（实例方法：`callContainer`、`CloudID`）。**小程序最低基础库 2.70.0** | 小程序/小游戏/小玩法/直播互动工具调用抖音云托管服务 |
| 返回体形态 | 回调 `success({ statusCode, header, data })`，其中 **`data` 为 string（需自行 `JSON.parse`）**；另有 `fail` / `complete` 回调 | 同上 |
| 登录（免登录） | 小程序经 `callContainer` 请求云托管服务时，**服务端可直接从 HTTP header 取得用户身份**：`X-TT-OPENID` / `X-TT-APPID` / `X-TT-UNIONID` / `X-TT-ANONYMOUS-OPENID`（匿名登录时仅可得该项）/ `X-TT-ENV` / `X-TT-SOURCE` / `X-Forwarded-For`。该能力**不带任何条件**，无需 `tt.login` + `code2Session` 置换，亦无需自行维护登录态；传 header `X-TT-EXCLUDE-CREDENTIALS: true` 可主动关闭凭证注入 | 免登录 |
| 敏感数据 | 小程序托管上云后，`tt.getUserInfo` / `tt.getUserProfile` / `tt.getPhoneNumber` 返回 `cloudID`（有效期 5 分钟），由云托管侧解密（仅支持 `Content-Type: application/json`，单请求最多 5 个 cloudID） | 免解密 |
| 免鉴权调开放能力 | 「云调用」：服务在抖音云环境内调用抖音开放服务 OpenAPI 时免 access_token（请求域名替换为云调用域名；建议用 HTTP） | 云调用 |
| 调用来源限制 | 抖音云提供「访问控制 / 外网入流量开关」：需显式开启外网入流量并配置授权路径，避免内网接口被外网调用产生越权；部分行业被要求后端必须部署在抖音云，且「仅限可信已加固的调用来源端访问」 | 操作限制 · 直播互动工具接入抖音云指南 |
| 免费额度 | **无免费额度**：2024-06-22 起「首次开通用户不再提供试用资源包」；此前入驻者一次性 180 元代金券（30 天有效，同一企业主体仅一次）。开通按量付费产品后账号预留 100 元不可提现 | 产品定价（含计费调整记录） |
| 计费（函数服务） | 调用次数 0.01 元/万次；内存使用量 弹性实例 0.762 元/万 GB·秒、预留实例 0.305 元/万 GB·秒；公网出流量 0.8 元/GB；持续交付流水线 1c2g 0.02 元/分钟；日志服务按写/读/索引流量与分区计费（分区 0.04 元/个/日，**空服务也约 2.4 元/月**）。官方示例：月调用 1 万次约 **4.53 元/月**（含日志与流水线） | 产品定价 |
| 计费（组件） | 文档型数据库-云数据库、配置中心：**当前免费、限频 200 QPS**（后续收费前提前一个月通知）；对象存储 / MongoDB / MySQL / Redis 等由火山引擎计费 | 产品定价 |
| 调试限频 | 直播互动工具口径：调试请求每分钟 100 次、每天 2000 次（**小程序侧未见同口径原文**，待平台侧复核；生产调用另受「访问控制」约束） | 直播互动工具接入抖音云指南 |
| 部署方式 | **不使用 IDE 的 `cloudfunctionRoot` 工程约定**：函数服务在抖音云控制台或经 `dycloud` CLI（`function:list` / `pull` / `deploy`）部署，容器服务经镜像推送（`container:push`）+「部署运行」发布；IDE 工具栏仅提供跳转抖音云控制台的入口 | 本地开发函数服务 · 抖音云 CLI 工具 · 自定义部署服务 · IDE 工具栏 |
| 函数服务工程形态 | 云端工程为**平铺 `<函数名>.js` + `package.json`**（另有模板 `index.js`）；**调用路径 = 文件相对路径去扩展名**（官方示例 `path:'/api/index'` ↔ 文件 `api/index.js`，故平铺即 `/<函数名>`）；入口 `module.exports = async function (params, context)`，**`params` 即 HTTP 请求体本身**（非 `{params:…}` 包装），返回值作为 Response Body；`context.trigger` ∈ `online` / `ide_debug` / `console_debug`，另有 `context.log/warn/error/info`、`context.set/status`、`context.path/query/headers`；源码必须 UTF-8、源文件数 ≤ 200、源代码（不含 node_modules）≤ 5MB、保留前缀 `__debug__` | 云函数Api · 本地开发函数服务（线上文件树实测） |

**对技术资产的结论**

1. **载体选型成立**：§1.1 的「Serverless 云函数 + 云数据库（文档型）」在平台侧有官方对应物 —— 抖音云函数服务 / 云托管 + 文档型云数据库（当前免费、限频 200 QPS）。原 `【待复核】` 可收口为「已检索，待平台侧复核」。
2. **调用形态须改写**：客户端应实现为 `tt.createCloud` + `Cloud.callContainer`（**平台无 `tt.cloud.callFunction` / `tt.callFunction`**），`data` 为 JSON 字符串需 parse 后套统一信封；已落在 `miniapp/core/cloud.js`。
3. **鉴权可依赖「免登录」**：身份由云托管服务端从 header 直接读取（`X-TT-OPENID`），无需 `tt.login` + `code2Session`；接口仍按「平台标识 + 本地 UUID」双字段预留，不阻塞开发。
4. **成本须正视**：**无免费额度**，按量付费（示例量级为每月数元）；「访问控制」需显式开放外网入流量与授权路径，须纳入部署清单。
